# Handoff sticky notes

Add entries when holding files for in-flight work. Format:

## YYYY-MM-DDTHH:MMZ (expires 24h) — <tool name>
Working: <one-line summary>
Touching: <file paths>
Branch: <branch name> (<size>)
Don't touch <files> until I push.

Empty file is normal state. Prune stale entries (older than date prefix indicates).
